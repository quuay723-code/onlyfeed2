# ONLYFEED v0.2

An iPhone-friendly installable web app with a fluid snap-scrolling feed, niche switching, saved videos, and real embedded YouTube videos. Curated proof-of-concept content only. YouTube may restrict some embeds; use the YouTube button if playback is unavailable. Autoplay and sound are subject to iPhone/YouTube browser policies. No TikTok/Instagram/Facebook integrations yet.

## Update GitHub Pages
Upload `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, and `icon-512.png` to the **root** of the existing GitHub repository, replacing files with the same names. Commit to main. Reload the site (if an old version persists, close and reopen or clear Safari website data).
