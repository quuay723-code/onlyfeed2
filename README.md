# ONLYFEED PWA

A mobile-first, installable website prototype. Includes niche switching, vertically swiped video feed, likes, saved videos, custom niches, and a home screen icon. Video clips are external demonstration URLs and require internet. They are NOT sourced from TikTok, Instagram, or Facebook; those platforms require compliant integrations and permissions.

## Publish without a Mac

1. Create a free GitHub account if needed.
2. Create a **public** repository named `onlyfeed`.
3. Upload the contents of this folder (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) to the repository root using GitHub's **Add file → Upload files**.
4. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
5. Wait for deployment, then visit `https://YOUR-GITHUB-USERNAME.github.io/onlyfeed/` in Safari on your iPhone.
6. Tap Share → Add to Home Screen → Add. The ONLYFEED icon will appear on the home screen and open without Safari chrome.

This is not yet hosted, and the downloadable ZIP itself cannot be installed directly. GitHub Pages is free for public repositories. A production app will need a backend, authorized content sources, moderation and privacy policies.
